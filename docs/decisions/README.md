# Decisiones arquitectónicas

Usar un ADR cuando una decisión técnica duradera tenga alternativas relevantes, consecuencias o costo de migración. No crear ADR para detalles rutinarios de implementación.

## Cómo agregar una decisión

1. Asignar el siguiente identificador estable `ADR-###`.
2. Copiar [adr-template.md](adr-template.md).
3. Registrar contexto, opciones consideradas, decisión, consecuencias y condiciones de revisión.
4. Enlazar el ADR desde la arquitectura, feature o plan afectados.
