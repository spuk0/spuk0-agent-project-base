# Índice de documentación

Este directorio separa la realidad verificada, la intención de producto, los planes de implementación y los aspectos operativos para evitar mezclarlos.

| Documento | Propósito |
|---|---|
| [project.md](project.md) | Alcance actual, actores, términos y exclusiones |
| [project-profiles.md](project-profiles.md) | Perfiles de inicio y criterio para dimensionar arquitectura |
| [product-vision.md](product-vision.md) | Dirección y contexto de roadmap |
| [architecture.md](architecture.md) | Límites técnicos y estructura verificada |
| [development.md](development.md) | Flujo local y comandos reproducibles |
| [features/README.md](features/README.md) | Capacidades del producto y criterios de aceptación |

| [deploy.md](deploy.md) | Contrato de publicación neutral respecto del proveedor |

## Reglas documentales

- Describir una conducta como implementada solo cuando exista evidencia en el repositorio.
- Identificar el comportamiento deseado como propuesto, planificado o roadmap.
- No versionar credenciales, hosts reales, rutas personales, identificadores de cuentas ni procedimientos privados de producción.
- Actualizar los índices al agregar una feature, plan o decisión.
- Usar fechas ISO (`YYYY-MM-DD`) e identificadores estables.
