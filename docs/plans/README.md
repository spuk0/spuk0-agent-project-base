# Planes de trabajo

Los planes describen **cómo y en qué orden** se completará un trabajo aprobado. Mantener un solo plan activo salvo que el trabajo paralelo sea intencional y explícito.

## Estados

- `propuesto`: requiere decisiones o aprobación.
- `activo`: guía el trabajo actual.
- `completado`: terminó con evidencia verificable.
- `cancelado`: dejó de aplicar, pero conserva su contexto.
