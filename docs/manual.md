# Manual de usuario

Este manual contiene únicamente comportamiento verificado en una aplicación en funcionamiento.

## Capacidades disponibles

Todavía no se verificaron capacidades visibles para una persona usuaria.

## Cómo agregar un procedimiento

Para cada feature finalizada, documentar:

1. Condiciones previas.
2. Acciones exactas de la persona usuaria.
3. Resultado visible esperado.
4. Limitaciones relevantes o pasos de recuperación.

No copiar descripciones del roadmap al manual.
