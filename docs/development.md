# Desarrollo local

## Requisitos previos

Enumerar versiones exactas de herramientas solamente después de verificarlas.

## Primera preparación

Documentar comandos reproducibles para restaurar dependencias y preparar la configuración exclusivamente local.

## Ejecución

Agregar comandos, puertos y resultados esperados verificados para cada proceso.

## Build y tests

Agregar comandos ejecutables desde la raíz que fallen de manera visible cuando falle cualquier componente obligatorio.

## Configuración y secretos

- Versionar únicamente ejemplos ficticios como `.env.example`.
- Usar variables de entorno, almacenes locales de secretos o archivos ignorados para valores reales.
- No depender de rutas personales absolutas.

## Diagnóstico

Registrar fallos recurrentes solo después de comprobar su causa y solución.
